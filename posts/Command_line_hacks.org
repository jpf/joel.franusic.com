<h2>Transfer multiple files between hosts using cut and paste</h2>
<p><span style="font-family: 'Courier New';">source$ tar -czf - <em>filenames</em> | uuencode `hostname`.`date +%s`.tar.gz</span></p>
<p>(copy the output into your clipboard, you can copy the command prompt too)</p>
<p><span style="font-family: 'Courier New';">destination$ pbpaste | uudecode # on Mac OS X</span></p>
